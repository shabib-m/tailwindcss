A modern, lightweight, and fully responsive theme for Backdrop CMS, built using Tailwind CSS.

## Features
- **Based on Basis:** Inherits all the robust layout and template structures from the default Backdrop Basis theme.
- **Tailwind CSS:** Utilizes the power of utility-first CSS for rapid styling.
- **Sticky Footer:** Automatically pushes the footer to the bottom of the page on all screen sizes.
- **Ready to Use:** No need to configure complex Layouts or Blocks. The theme is designed to work out-of-the-box.
- **RTL Support:** Fully tested and optimized for Right-to-Left (Arabic) languages.
- **Customizable:** Includes a `theme-settings.php` (In Progress) to allow users to change colors and other options without touching the code.

## Status
🚧 **Developer Version (Dev)** 
This theme is currently in active development. We are looking for feedback, bug reports, and contributions to help improve it before a stable release.

## Installation
1. Download or clone this repository into your `themes` directory.
2. Go to `Admin > Appearance` in your Backdrop site and enable the theme.
3. (Optional) If you are developing, run `npm install` and `npm run build` to compile the Tailwind CSS.
